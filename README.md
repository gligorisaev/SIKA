# SIKA ERP Dashboard

Private repository for SIKA ERP data analytics and business intelligence dashboard.

## 📊 Features

- **Interactive HTML Dashboard** - Real-time invoice analytics
- **DBF to JSON Converter** - Convert Clipper DBF databases to JSON
- **Multi-chart Analytics**:
  - Invoice trend analysis
  - Document type distribution
  - Monthly revenue tracking
  - Top 10 customers analysis
- **Monthly Invoice Filtering** - Filter invoices by month
- **Full Macedonian/English field support**

## 🚀 Usage

1. **Convert DBF to JSON or CSV:**
   ```bash
   python dbf_to_json.py NASLOV.DBF naslov.json
   ```

2. **Open Dashboard:**
   - Double-click `dashboard.html`
   - Or open in browser

3. **Load Data:**
   - Dashboard auto-loads `NASLOV.csv` or `naslov.json`
   - Or use file picker to load other data

## 📁 Files

- `dashboard.html` - Main analytics dashboard
- `dbf_to_json.py` - DBF converter utility

This is a private repository containing business data. Do not share publicly.
